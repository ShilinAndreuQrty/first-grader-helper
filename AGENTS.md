# Правила разработки

## Общие принципы

- Проект — модульный монолит: React/VKUI в `frontend`, FastAPI в `backend`.
- Публичный API имеет префикс `/api`; служебные проверки — `/health` и `/ready`.
- Новые функции должны работать без production-ключей в browser/dev режиме.
- Секреты хранятся только в переменных окружения backend. Файлы `.env` не коммитятся.
- Время в БД хранится в UTC, пользовательское время отображается в `Europe/Moscow`.
- Пользовательский и редакторский текст нельзя рендерить как произвольный HTML.

## Код

- Python 3.12, типизация, Ruff, Pytest.
- TypeScript в строгом режиме, ESLint, Vitest, React Testing Library, Playwright.
- Комментарии объясняют ограничения интеграций и неочевидные решения. Не комментируйте
  очевидные присваивания и названия функций.
- Внешние сервисы подключаются через небольшие адаптеры с таймаутом и проверкой ответа.
- Любая административная проверка роли выполняется на backend.

## Git

- Conventional Commits.
- В коммит добавляются только файлы текущего шага.
- Перед коммитом: `git diff`, `git diff --cached`, `git diff --check` и минимальные
  проверки затронутого слоя.
- Не коммитить `.env`, ключи, дампы БД, `node_modules`, `.venv`, сборки и отчёты тестов.
