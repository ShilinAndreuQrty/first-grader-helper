# Интеграция 2ГИС

Проверено 29 июля 2026 года. Использовались только публичные страницы объектов и
документированные интерфейсы 2ГИС.

## Решение

Раздел карты работает в три уровня:

1. каталог корпусов, кабинетов и прямые проверенные ссылки 2ГИС — всегда;
2. FloorsJS — для корпусов, где документированный виджет успешно вернул событие
   `init` и список этажей;
3. MapGL с `floorControl` — для подтверждённых координат, если включён флаг и
   задан браузерный ключ.

FloorsJS выбран первым вариантом для поэтажной навигации: он не требует
MapGL-ключа и [предоставляется бесплатно](https://docs.2gis.com/en/maps/overview).
MapGL остаётся дополнением, а не обязательной зависимостью.

## Spike FloorsJS

Для контроля официальный примерный `complexId` успешно вернул 8 этажей и 195
организаций. Затем тем же
[документированным способом инициализации](https://docs.2gis.com/en/maps/others/floorsjs/overview)
проверены ID подтверждённых страниц корпусов ТулГУ.

| Корпус | Проверенный `complexId` | Результат |
|---|---:|---|
| Главный и 9-й | `5067185235966202` | 8 уровней, виджет работает |
| №1 | — | `init` не получен, только внешний fallback |
| №2 | — | `init` не получен, MapGL/fallback |
| №3 | `70000001096985234` | 4 этажа |
| №5 | `5067533128372217` | 4 этажа |
| №6 | `5067533128433198` | 5 уровней |
| №8 | — | `init` не получен, только внешний fallback |
| №10 | `5067533128372227` | 5 этажей |
| №11 | — | `init` не получен, только внешний fallback |
| №12 | `5067077861790182` | 4 этажа |
| Лабораторный №6 | — | `init` не получен, только внешний fallback |

Главный и 9-й корпуса остаются двумя техническими записями для сопоставления
аудиторий, но в каталоге показываются одним пунктом: это одно здание со входом
с улицы Смидович.

Документация описывает `complexId` как ID здания, но не содержит метода получения
этого значения из карточки или координат. Поэтому приложение не ищет его через
внутренние endpoints и не подставляет ID наугад. ID сохраняется только после
успешного `init`. Наличие этажей в обычном приложении 2ГИС само по себе не
считается подтверждением доступности через публичный API.

После инициализации FloorsJS возвращает список этажей и ID организаций. Эти
данные используются только самим виджетом: приложение не сохраняет и не
проксирует их. Документированный API не даёт универсального поиска кабинетов
ТулГУ. Поэтому кабинет показывается только из собственной проверенной базы, а
неизвестный кабинет получает честный fallback.

## MapGL и этажи

[MapGL показывает этажные планы только для выбранных зданий](https://docs.2gis.com/en/mapgl/map/configuration/floors)
при масштабе 18 и выше. `floorPlanId` и индекс этажа разрешено получать во время
работы через `floorplanshow`; заранее вычислять их по координатам нельзя. Пока
для корпусов ТулГУ нет подтверждённого соответствия кабинет → floor plan,
приложение не переключает этаж программно.

MapGL загружается отдельным динамическим bundle только при открытии раздела и
только если:

- `DGIS_ENABLED=true`;
- для корпуса нет проверенного FloorsJS-комплекса;
- координаты подтверждены;
- задан `VITE_DGIS_MAPGL_KEY`.

При unmount экземпляр MapGL уничтожается. Ошибка, блокировка или окончание ключа
заменяют карту понятным сообщением; каталог и ссылка на объект остаются рабочими.
Places, Suggest и Routing API не подключаются.

## Общежития

Каталог общежитий сверен 29 июля 2026 года с
[официальным перечнем ТулГУ](https://tulsu.ru/facilities/dormitory) и публичными
карточками 2ГИС. В перечне есть №1, №2, №3, №4/1, №4/2, №6/1, №6/2, №7, №8,
№9, №10 и №11; общежития №5 в источнике нет.

Для каждой записи сохранены координаты из видимой ссылки «Маршрут» на карточке
2ГИС и прямой URL вида `/firm/{id}`. Поисковые URL не генерируются. Общежития не
участвуют в распознавании корпуса из расписания: их aliases содержат слово
«общежитие» или сокращение «общ», а не голый номер.

## VK WebView и CSP

Production Caddy сейчас не задаёт `Content-Security-Policy`, поэтому собственная
CSP не блокирует loader/iframe FloorsJS или запросы MapGL. FloorsJS для
главного/9-го корпуса проверен внутри реального VK WebView: loader, iframe,
этажи, встроенный поиск и атрибуция загрузились. Проверку нужно повторять после
каждого изменения политики VK или добавления CSP. Если CSP появится, разрешённые
домены следует брать из актуальной документации/ответов 2ГИС, а не расширять
политикой `*`.

Виджеты и карты сохраняют встроенную атрибуцию 2ГИС. Она не перекрывается стилями
приложения. Это соответствует [правилам API 2ГИС](https://law.2gis.ru/api-rules).

## Ключи и стоимость

`VITE_DGIS_MAPGL_KEY` — браузерный ключ и поэтому виден в bundle. Его нельзя
хардкодить: в Platform Manager ключ нужно ограничить production `Origin` и
`Referer`, что [поддерживается настройками ключа](https://docs.2gis.com/en/platform-manager/subscription/managing-keys).

Демо-ключ создаётся один раз и
[действует один месяц с лимитами запросов](https://docs.2gis.com/en/platform-manager/subscription/keys).
После окончания срока или исчерпания блокирующего лимита запросы MapGL
возвращают ошибку, но каталог продолжает работать. MapGL использует Map Tiles;
стоимость зависит от успешно обработанных запросов к плиткам согласно
[правилам тарификации](https://docs.2gis.com/en/platform-manager/subscription/pricing).

## Конфигурация

```dotenv
DGIS_ENABLED=false
VITE_DGIS_MAPGL_KEY=
```

Для локального запуска без ключа можно включить только `DGIS_ENABLED=true`:
проверенные FloorsJS-корпуса будут работать, остальные останутся на внешнем
fallback. Перед production build значение флага передаётся в
`VITE_DGIS_ENABLED`; ключ передаётся только как build argument и не хранится в
Git.
