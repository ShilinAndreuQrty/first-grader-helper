# Release checklist

- [ ] Все backend/frontend/E2E проверки зелёные.
- [ ] Миграции и seed проходят на чистой PostgreSQL.
- [ ] Создан и проверен backup/restore.
- [ ] `APP_ENV=production`, dev auth выключен, cookie Secure.
- [ ] Сильные DB/app secrets; dev-ключи заменены.
- [ ] CORS содержит только production origin.
- [ ] DNS и TLS проверены снаружи.
- [ ] VK URL во всех placements указывает на production HTTPS.
- [ ] VK launch signature протестирована внутри мобильного и web VK.
- [ ] Заполнены владелец/контакт/политика конфиденциальности.
- [ ] FAQ `needs_review` разобран; временные сведения имеют дату проверки.
- [ ] Группы и тьюторы текущего учебного года загружены и подтверждены.
- [ ] Серия собраний имеет границы, исключения и подтверждённый occurrence.
- [ ] Координаты 2ГИС проверены, ключ ограничен доменом.
- [ ] Внешние уведомления включены только после opt-in и реального smoke-test.
- [ ] Tulsu stale-cache, пустое расписание и недоступность проверены.
- [ ] Проверены mobile viewport, desktop, светлая/тёмная тема и клавиатура.
- [ ] Создан Git tag и записан план rollback.
