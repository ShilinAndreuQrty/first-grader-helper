# Руководство редактора

Админ-панель открывается из «Ещё» только для `superadmin`,
`content_editor` или `events_editor`. Сервер проверяет роль независимо от UI.

## Собрания и мероприятия

В верхней форме выберите тип записи:

- для ближайшего собрания нужны дата, время начала и место; регистрации и
  внешней ссылки у собрания нет;
- для мероприятия дополнительно указываются название и ссылка на регистрацию.
  Кнопка «Я приду» сохраняет участие и открывает эту ссылку.

Опубликованную запись можно отредактировать или отменить. Отменённое событие
можно вернуть либо удалить вручную. Изменение и отмена создают уведомления для
зарегистрированных пользователей. Завершённые записи перестают показываться
после полуночи по Москве в день проведения.

В списке рядом с каждым событием отображается число регистраций. «Сводка»
показывает ближайшие и отменённые события, активные регистрации,
зарегистрированных пользователей и недавние административные изменения.

## Обратная связь и пользователи

Сообщения из формы «О проекте» находятся в блоке «Обратная связь по проекту».
Список пользователей показывает основную группу и время последней активности;
переход по строке открывает профиль VK.

## Демо-режим

Кнопка «Сбросить мои данные» очищает только пользовательское состояние того
администратора, который её нажал: группы, прогресс маршрута, регистрации,
настройки и уведомления. Роли, сессия и созданные события сохраняются.

## Импорт групп и тьюторов

Заполните `backend/examples/tutors.csv` без лишних персональных данных:

```csv
group_code,academic_year,tutor_name,tutor_vk_url,description
220031-22,2026/27,Имя Фамилия,https://vk.ru/id000000,Тьютор
```

Номер группы содержит шесть цифр и, при наличии, дефис с двумя цифрами.
Типографские варианты дефиса и пробелы нормализуются, цифры не изменяются.

Проверка и импорт:

```bash
python -m app.students.importer tutors.csv --validate-only
python -m app.students.importer tutors.csv
```

Импортированные тьюторы остаются `needs_review`. Не скрейпьте фотографии и
личные страницы; используйте только данные, на публикацию которых есть согласие.
