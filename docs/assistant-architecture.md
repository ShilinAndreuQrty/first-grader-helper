# Архитектура помощника

## Публичный контракт

`POST /api/assistant/query` принимает вопрос до 500 символов и необязательный
`selected_faq_id`. Ответ имеет один из типов:

- `answer` — одно опубликованное совпадение высокой уверенности;
- `suggestions` — 2–3 близких канонических вопроса;
- `clarification` — короткий запрос требует выбора темы;
- `not_found` — опубликованного знания нет.

Числовой score наружу не возвращается. Клиент получает `high`, `medium` или `low`.

## Детерминированный provider

`DeterministicRetrievalProvider`:

1. нормализует регистр, `ё/е`, тире, пунктуацию и пробелы;
2. исключает не опубликованные, удалённые и просроченные записи;
3. сравнивает вопрос с канонической формулировкой и aliases;
4. учитывает token overlap и небольшое совпадение по ответу;
5. применяет фиксированные пороги для ответа, вариантов и отказа.

В PostgreSQL миграция добавляет `pg_trgm` и русский `tsvector`-индекс. Python-ranking
остаётся финальным объяснимым слоем и обеспечивает одинаковое поведение в SQLite-тестах.

## Безопасность и приватность

- в ответ нельзя передать `draft`, `needs_review` или `archived`;
- `selected_faq_id` также проходит проверку публичности;
- произвольный HTML не хранится и не рендерится, используется ограниченный Markdown;
- запрос ограничен по длине и частоте;
- для `not_found`/`clarification` сохраняются SHA-256 fingerprint и короткая подсказка
  с замаскированными цифрами, а не полный диалог;
- история диалога по умолчанию остаётся на устройстве пользователя.

## Опциональный AI-слой

Порт `AssistantAnswerProvider` отделяет публичный контракт от реализации. AI-provider
не включён. Если команда решит его добавить, он получит только запрос и top-N
опубликованных FAQ ID, вернёт строгий JSON, а все ID будут перепроверены. Таймаут,
невалидный JSON, неизвестный ID или лимит бюджета немедленно возвращают результат
детерминированного provider.
