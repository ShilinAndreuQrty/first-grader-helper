# Оценка качества помощника

## Baseline

Seed фиксирует 8 категорий и 60 исходных записей. Автотесты проверяют:

- русский вопрос с опечаткой `тютор`;
- aliases;
- `answer`, `clarification` и `not_found`;
- запрет выдачи `needs_review`;
- детерминированность source key и импорт многоабзацного ответа.

## Набор оценки

До пилота редактор готовит JSONL без персональных данных:

```json
{"query":"кто такой тютор", "expected_source_key":"category-1-...-kto-takoi-tyutor"}
{"query":"стипендия", "expected_type":"clarification"}
{"query":"неизвестная тема", "expected_type":"not_found"}
```

Минимальные метрики: top-1 accuracy для однозначных вопросов, recall@3 для вариантов,
доля корректных отказов, p95 latency и доля переходов к тьютору.

## Порядок улучшений

1. Проверить ошибки редактором.
2. Добавить aliases и исправить пороги.
3. При необходимости сравнить PostgreSQL FTS с embeddings.
4. Только после измеримой пользы тестировать rerank/grounded generation.

AI нельзя включать по субъективному впечатлению. ADR должен содержать качество,
задержку, стоимость и риски на одном зафиксированном evaluation-наборе.
