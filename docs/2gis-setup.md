# Настройка 2ГИС

Карта — прогрессивное улучшение. Каталог зданий, кабинетов и кнопка перехода
в 2ГИС работают без ключа.

1. Создайте MapGL-ключ в кабинете 2ГИС.
2. Ограничьте браузерный ключ production-доменом и локальными origin команды,
   если кабинет поддерживает такие ограничения.
3. Укажите его в `VITE_DGIS_MAPGL_KEY`. Этот ключ технически публичен, потому
   что передаётся браузеру; серверные ключи поиска в эту переменную класть нельзя.
4. Координаты добавляйте только после проверки. Без координат здание останется
   в текстовом каталоге и будет иметь рабочую внешнюю ссылку.

MapGL загружается отдельным динамическим bundle только после открытия карты.
Для VK WebView включены `disableDragging` и `enableTwoFingerDragging`, а
`floorControl` показывается только когда 2ГИС располагает этажными данными.

Проверенные источники начального seed:

- официальный ТулГУ: `https://tulsu.ru/facilities/academic-building/4`;
- страница ИПМКН с дирекцией в кабинете 425:
  `https://tulsu.ru/faculty-landing/institut-prikladnoy-matematiki-i-kompyuternykh-nauk/campus-life`.

Кабинеты 403, 123 и 125 импортированы как `needs_review` и публично не
показываются до проверки редактором.
